# SwiftData-ToDo-Practice

A practice project built to learn SwiftData and MVVM architecture.

## Screenshots
![Main Screen](Screenshots/main.png)
![Add Task](Screenshots/add.png)

## Stack
- Swift / SwiftUI
- SwiftData
- MVVM

## Features
- Add tasks with title, note and priority
- Delete task on completion
- Tasks sorted by date (newest first)
- Empty state placeholder
- Data persists between app launches

## Planned Features
- Display completed tasks separately

## Requirements
- iOS 17+
- Xcode 15+
